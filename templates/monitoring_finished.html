Metodología y Proceso Técnico

1. Fundamentos Teóricos y Normativos

El análisis acústico se fundamenta en dos normas técnicas complementarias:

  • ISO/TR 25417:2007 - Especifica las definiciones de cantidades acústicas y términos utilizados en documentos de medición de ruido preparados por el Comité Técnico ISO TC 43, Acústica, Subcomité SC 1, Ruido.
  • NTP ISO 9612:2010 - Norma Técnica Peruana que establece los métodos de medición de la exposición al ruido en el trabajo para la evaluación de la pérdida auditiva inducida por ruido, adoptando los lineamientos de la norma internacional ISO 9612.

Aplicación de NTP ISO 9612:2010 - Exposición Laboral

La norma peruana NTP ISO 9612:2010 establece el método para calcular el nivel de exposición al ruido normalizado para una jornada laboral de 8 horas:

$$L_{EX,8h} = L_{p,A,eqTe} + 10 \log_{10} \left( \frac{T_e}{T_0} \right) \, \text{dB}$$

Donde:

  • $L_{EX,8h}$ = Nivel de exposición al ruido normalizado para 8 horas
  • $L_{p,A,eqTe}$ = Nivel de presión sonora continuo equivalente ponderado A para $T_e$
  • $T_e$ = Duración efectiva de la jornada laboral (horas)
  • $T_0$ = Duración de referencia = 8 horas (jornada laboral estándar)
# Implementación de NTP ISO 9612:2010 en app.py
def calcular_exposicion_8h(Lp_eqT, duracion_horas):
    """
    Calcula el nivel de exposición normalizado para 8 horas
    según NTP ISO 9612:2010
    """
    T_e = duracion_horas  # Duración efectiva en horas
    T_0 = 8.0            # Duración de referencia (8 horas)
    
    # Aplicación directa de la fórmula NTP ISO 9612:2010
    L_EX_8h = Lp_eqT + 10 * np.log10(T_e / T_0)
    
    return L_EX_8h

Esta fórmula permite normalizar cualquier medición de ruido a una jornada estándar de 8 horas, facilitando la comparación con límites de exposición ocupacional establecidos en la legislación peruana.

2. Parámetros de Referencia

Presión de referencia:
$p_0 = 2 \times 10^{-5}$ Pa (20 μPa)
Exposición sonora de referencia:
$E_0 = 4 \times 10^{-10}$ Pa²·s

Cálculo del Nivel de Presión Sonora Equivalente (LAeq)

$$L_{p,eqT} = 10 \log_{10}\left(\frac{\frac{1}{T}\int_{t_1}^{t_2} p^2(t) dt}{p_0^2}\right)$$ 
# Implementación en app.py líneas 100-102
T = len(data) / rate  # Duración total
mean_squared = np.mean(data**2)  # Valor cuadrático medio
Lp_eqT = 10 * np.log10(mean_squared / (p0**2)) if mean_squared > 0 else 0

La implementación calcula directamente el valor cuadrático medio de la presión sonora y aplica la transformación logarítmica según ISO 25417.

Cálculo del Nivel Máximo de Presión Sonora

$$L_{p,max} = 10 \log_{10}\left(\frac{p_{max}^2}{p_0^2}\right)$$ 
# Implementación en app.py líneas 103-104
p_max = np.max(np.abs(data))  # Valor máximo absoluto
Lp_max = 10 * np.log10((p_max**2) / (p0**2)) if p_max > 0 else 0

Se utiliza el valor absoluto máximo para capturar tanto picos positivos como negativos de la señal.

Cálculo de la Exposición Sonora (ET)

$$E_T = \int_{t_1}^{t_2} p^2(t) dt = \frac{\sum_{i=1}^{N} p_i^2}{f_s}$$ 
# Implementación en app.py líneas 105-106
ET = np.sum(data**2) / rate  # Exposición sonora total
LE = 10 * np.log10(ET / E0) if ET > 0 else 0  # Nivel de exposición

La exposición sonora se calcula como la suma de los cuadrados de las muestras dividida por la frecuencia de muestreo, representando la energía acústica total.

Cálculos Adicionales según ISO 25417

# Energía sonora (J) - app.py líneas 107-108
J_energy = ET  # Energía sonora igual a exposición sonora
LJ = 10 * np.log10(J_energy / J0) if J_energy > 0 else 0

# Intensidad sonora promediada - app.py líneas 109-110
IT = mean_squared / (rho * c)  # I = p²/(ρc)
LI = 10 * np.log10(IT / I0) if IT > 0 else 0

Se calculan parámetros adicionales como la energía sonora (LJ) y la intensidad sonora promediada (LI) siguiendo las relaciones establecidas en ISO 25417.

Cálculo del LAeq General Combinado

$$\overline{p^2} = \frac{\sum_{i=1}^{n} p_i^2 \cdot T_i}{\sum_{i=1}^{n} T_i}$$ $$L_{Aeq,general} = 10 \log_{10}\left(\frac{\overline{p^2}}{p_0^2}\right)$$ 
# Función analisis_general() - app.py líneas 580-610
def analisis_general(escenario_id, microfono_id):
    """
    Calcula el LAeq general combinando todos los audios del escenario
    mediante promedio energético ponderado por duración
    """
    resultados = AnalysisResult.query.filter_by(
        escenario_id=escenario_id, 
        microfono_id=microfono_id
    ).all()
    
    total_duration = 0.0
    total_ET = 0.0
    weighted_sum_pressure_sq = 0.0
    
    for res in resultados:
        global_result = json.loads(res.global_result)
        duration = float(global_result.get("duration", 0))
        Lp_eqT = float(global_result.get("Lp_eqT", 0))
        
        # Convertir dB a escala lineal: p² = p₀² · 10^(Lp_eqT/10)
        pressure_sq = (2.0e-5)**2 * (10 ** (Lp_eqT / 10))
        
        total_duration += duration
        total_ET += float(global_result.get("ET", 0))
        weighted_sum_pressure_sq += pressure_sq * duration
    
    # Promedio ponderado por duración (combinación energética)
    mean_pressure_sq = weighted_sum_pressure_sq / total_duration
    Lp_eqT_global = 10 * np.log10(mean_pressure_sq / (2.0e-5)**2)
    
    # Aplicar NTP ISO 9612:2010 para exposición de 8 horas
    duracion_horas = total_duration / 3600.0
    L_EX_8h = Lp_eqT_global + 10 * np.log10(duracion_horas / 8.0)
    
    return {
        'Lp_eqT': Lp_eqT_global,
        'L_EX_8h': L_EX_8h,  # Exposición normalizada 8h
        'duration': total_duration,
        'ET': total_ET,
        'LE': 10 * np.log10(total_ET / 4e-10) if total_ET > 0 else 0
    }

El LAeq general se calcula combinando todos los audios mediante un promedio ponderado por duración en escala lineal, luego convertido a escala logarítmica. Adicionalmente, se calcula la exposición normalizada para 8 horas según NTP ISO 9612:2010.

Diccionario de Términos Técnicos

LAeq (Lp,eqT)
Nivel de presión sonora continuo equivalente ponderado A. Representa el nivel de ruido constante que contendría la misma energía acústica que el ruido variable medido.
Lp,max
Nivel máximo de presión sonora. El mayor valor de nivel de presión sonora registrado durante el período de medición.
ET
Exposición sonora (Sound Exposure). Integral temporal del cuadrado de la presión sonora durante un evento acústico específico.
LE (LE,T)
Nivel de exposición sonora. Expresión logarítmica de la exposición sonora, normalizada respecto a la exposición de referencia.
LJ
Nivel de energía sonora. Relacionado con la energía acústica total contenida en una señal sonora.
LI (LI,T)
Nivel de intensidad sonora promediado en el tiempo. Medida de la potencia acústica que fluye a través de una superficie unitaria.
p₀
Presión sonora de referencia = 20 μPa. Umbral de audición humana utilizado como referencia para cálculos logarítmicos.
E₀
Exposición sonora de referencia = 4×10⁻¹⁰ Pa²·s. Valor de referencia para normalizar la exposición sonora.
ISO/TR 25417:2007
Norma técnica internacional que define cantidades acústicas y términos para medición de ruido, proporcionando terminología armonizada.
NTP ISO 9612:2010
Norma Técnica Peruana que establece métodos para la determinación de la exposición al ruido en el trabajo, adoptando la ISO 9612.
dB (Decibel)
Unidad logarítmica utilizada para expresar la relación entre dos valores de potencia o intensidad, comúnmente usada en acústica.
Pa (Pascal)
Unidad de presión en el Sistema Internacional. En acústica, se utiliza para medir la presión sonora.
Hz (Hertz)
Unidad de frecuencia que indica el número de ciclos por segundo. Utilizada para caracterizar señales de audio.
