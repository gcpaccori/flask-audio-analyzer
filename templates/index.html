Módulo de Calibración

Comparación entre la medición de pistófono y la lectura obtenida por la aplicación en ventanas cortas.

Proceso reportado: se aplica un tono patrón del pistófono, se registra el nivel global y por segundo, luego se compara con el resultado extraído por la aplicación para verificar desviación en dB. Como el pistófono no dura mucho tiempo, el análisis se realiza en ventanas cortas y se recomienda repetir ciclos para robustecer la estadística. Esta vista es demostrativa y no ejecuta adquisición automática de datos.

Comparación por segundo
Fórmulas aplicadas al gráfico
\(e_i = y_i-x_i\), \(v_i(\%) = \frac{e_i}{x_i}\times 100\), límites de referencia: \(v_i = +1\) y \(v_i = -1\).

Serie temporal sincronizada para inspeccionar sesgo local, drift y variabilidad intra-ensayo.

Comparación global
Fórmula aplicada al resumen
\(\bar{x}=\frac{1}{n}\sum x_i\), \(\bar{y}=\frac{1}{n}\sum y_i\), \(\Delta_{global}=|\bar{y}-\bar{x}|\).

Resumen de medias globales (pistófono vs sistema) para validar concordancia de nivel absoluto.

Fórmula de fila por segundo
\(\Delta_i = |y_i-x_i|\).

Tabla base segundo a segundo para trazabilidad de errores y auditoria del procesamiento.

Fórmulas de desempeño
\(MAE=\frac{1}{n}\sum |e_i|\), \(RMSE=\sqrt{\frac{1}{n}\sum e_i^2}\), \(s_e=\sqrt{\frac{1}{n}\sum(|e_i|-\overline{|e|})^2}\), \(s_e^2=\mathrm{Var}(|e|)\), \(MAPE=\frac{100}{n}\sum\frac{|e_i|}{|x_i|}\), \(U_{k=2}=2\cdot SEM\), \(P90=Q_{0.90}(|e|)\), \(r=\mathrm{corr}(x,y)\), criterio final: \(MAPE \leq 1\).
